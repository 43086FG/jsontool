# Screenshots / 截图

本目录存放 README 中引用的界面截图，均取自真实运行的桌面应用（1280×960 窗口，2 倍缩放导出为 1920×1440 PNG）。除 `rtl.png` 为阿拉伯语界面外，其余为英文界面。

Screenshots referenced by the README, captured from the running app (1280×960 window, exported at 2× as 1920×1440 PNG). All use the English UI except `rtl.png` (Arabic).

| File | Scene / 场景 |
| --- | --- |
| `home.png` | 主页项目列表 / Home project list |
| `tree.png` | 树形视图（嵌套对象与数组） / Graph tree view with nested objects and arrays |
| `detail.png` | 详情编辑页 / Node detail editor |
| `source.png` | 源码模式（行号与括号着色） / Source mode with line numbers and bracket colors |
| `settings.png` | 设置面板（外观 / 语言 / 导出路径） / Settings sheet |
| `toolbox.png` | 工具箱（UUID 与时间戳转换） / Toolbox |
| `dark.png` | 深色主题 / Dark theme |
| `rtl.png` | 阿拉伯语 RTL 布局 / Arabic RTL layout |

重新截图时启动 `npm run dev`，在浏览器预览中按上表场景操作并截取 1280×960 窗口即可。

To regenerate, run `npm run dev`, reproduce each scene in the browser preview and capture a 1280×960 window.
